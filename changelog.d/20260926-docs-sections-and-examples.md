### Changed

- **The documentation site is split into sections, each with its own
  navigation: Get started, Features, Memory, Safety, Running it,
  Reference, and Development.** The long Features, Safety and
  production pages became one short page per topic. Working on
  Hostwarden itself — the development checkout, the lab, validating a
  branch — moved out of the admin pages into Development.

### Added

- **The docs show what Hostwarden records, with real examples.** A
  first session from start to finish, a host's `memory.md`,
  `guests.md`, `storage.md` and network profile, the journal line and
  its changelog entry, to-do lists, plans and decisions, and the
  Mermaid maps `bin/hostwarden-map` draws, rendered on the site.
  A Reference section lists example prompts, skills, scripts,
  environment variables and a glossary.
